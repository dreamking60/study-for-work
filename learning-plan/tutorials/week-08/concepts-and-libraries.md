# Week 08 概念与库说明

## 这周你到底在学什么
这周不是单纯“学会用 kubectl”，而是开始理解：
- 什么是 K8s 资源对象
- 什么是控制器
- 为什么 Reconcile 是核心

## 这周最重要的概念

### CRD
- 它是什么：你自己定义的 Kubernetes 资源类型
- 为什么要学：你要让 K8s 能认识 `RoomService`

### Spec
- 它是什么：你希望系统变成什么样
- 为什么重要：控制器就是围绕“期望状态”工作的

### Status
- 它是什么：系统当前实际状态
- 为什么重要：没有 Status，你就很难知道控制器有没有把事情做成

### Reconcile
- 它是什么：比较期望状态和当前状态，再做收敛动作
- 为什么重要：这是控制器最核心的循环

## 这周最重要的框架

### Kubebuilder
- 为什么用它：它帮你生成标准 Controller 项目骨架
- 为什么不手写：你现在的重点是理解控制器思路，不是和脚手架细节死磕

### `controller-runtime`
- 为什么会出现：Kubebuilder 生成的项目就是基于它
- 你现在先不用全懂什么：先会读 `Reconcile` 签名和对象获取逻辑就够了

## 这周你最容易误解的地方
- 以为控制器就是“写个脚本 apply 资源”
- 以为 Spec 和 Status 没区别
- 以为 Week 08 的重点是部署所有组件

其实这周最重要的是：
- 理解对象模型
- 理解控制循环
- 跑通最小闭环
