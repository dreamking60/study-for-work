## 使用规则
- `tutorials/` 是唯一正文目录。
- 优先进入每周文件夹，先读 `README.md`，再按 `day-1.md` 到 `day-7.md` 顺序执行。
- 每次只做当前周教程，不要同时开多个大方向。
- 每个教程都要求你产出代码、测试和运行记录，而不是只看文档。
