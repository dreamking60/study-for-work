# Week 07 教程：给 `room-orchestrator` 补幂等、重试和补偿

## 本周目标
- 加幂等
- 加重试
- 做至少两类异常演练

## 本周主要改哪些文件
- `internal/manager/manager.go`
- `internal/scheduler/scheduler.go`
- 如需要新增 `internal/retry/`
- 如需要新增 `internal/idempotency/`

## 第 1 天：找出最该幂等的入口
优先考虑：
- 创建房间
- 开始房间
- 结束房间

完成标准：
- 重复请求不会造成重复副作用

建议优先保护：
- 创建房间
- 启动房间

## 第 2 天：实现重试
今天先做最简单可解释版本：
- 限次数
- 间隔固定或退避

完成标准：
- 你能从日志或事件里看见第几次重试

## 第 3 天：加失败隔离
你至少要有一种处理方式：
- 补偿
- 死信
- 失败队列

这一版推荐先做最简单的失败队列。

## 第 4 天：演练依赖超时
模拟一个依赖失败场景。

你要记录：
- 发生了什么
- 系统怎么表现
- 怎么恢复

建议把演练输入和期望输出写成脚本或文字 checklist。

## 第 5 天：演练重复消息或堆积
再做一类异常：
- 重复消息
- 消息堆积
- 调度延迟

今天不要只说“理论上会怎样”，要留下实际记录。

## 第 6 天：输出复盘
复盘只写：
- 根因
- 当前保护机制
- 还差什么

## 第 7 天：收口到项目材料
把本周成果整理成之后简历可用的句子和案例。

## 本周最终自检命令
```bash
go test ./...
go run ./cmd/orchestrator
```
