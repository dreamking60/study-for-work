# Week 04 Day 1：先把连接生命周期画出来

## 今天你要完成什么
今天不要先写心跳代码，你先得知道：
- 连接从哪里开始
- 什么时候进入房间
- 什么时候算失活
- 什么时候该清理

## 为什么今天先画状态图
因为如果你自己都说不清生命周期，后面写出来的清理逻辑大概率是补丁式的。

## 今天你至少要列出这些状态
- 新建连接
- 已鉴权
- 已加入房间
- 活跃
- 失活
- 已断开

## 今天完成后的标准
- 你已经画出一张简单状态图
- 你知道心跳和超时会落在哪两个环节

## 今天会用到的库和最小代码

### 连接状态最少会映射到这些字段
```go
type Session struct {
    ConnID     string
    UserID     string
    RoomID     string
    LastSeenAt time.Time
}
```
