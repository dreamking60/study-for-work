# 简历话术（按新项目主线）

## 项目 0：`opsctl`
- 负责构建 Go 工程 CLI，完成配置加载、命令分发、错误处理和单元测试，为后续服务提供统一调试与运维入口。
- 将早期学习代码沉淀为可复用工具链，降低后续项目的环境切换和本地排障成本。

## 项目 1：`edge-gateway`
- 游戏岗：负责实时接入网关开发，完成连接管理、会话鉴权、消息路由和限流控制，支撑高并发在线场景下的稳定接入。
- 游戏岗：针对连接生命周期和异常链路补齐日志、压测和性能分析，提升高峰期延迟与稳定性表现。
- 平台岗：设计统一入口服务，沉淀配置、可观测性和错误治理能力，为后续服务治理和部署扩展打基础。

## 项目 2：`room-orchestrator`
- 游戏岗：实现房间 / 任务生命周期状态机，支持超时回收、失败重试和事件记录，提升业务流程可靠性。
- 平台岗：负责调度与编排子模块开发，完成幂等、补偿和异常演练设计，并输出 HLD/LLD 与测试用例。

## 项目 3：`cluster-operator`
- 平台岗：基于 Kubebuilder 实现最小部署控制器，管理房间服务实例的创建、更新与状态同步。
- 平台岗：补齐 Docker、kind、CI/CD 和部署文档，形成从 Go 服务开发到本地集群交付的完整链路。
- 游戏岗：沉淀工具开发和运营支撑能力，证明对服务部署、资源调度和线上问题定位的理解。
