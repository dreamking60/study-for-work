# 每周检查清单

## 每周必做
- [ ] 完成本周 tutorials 里的所有 Day 任务
- [ ] 每段代码都能独立运行
- [ ] 画一张架构图（系统组件与交互流程）
- [ ] 写一篇知识沉淀笔记（发现、困惑、总结）
- [ ] 代码提交到本地 git（`git add . && git commit -m "weekN: ..."`）

## 交付物标准
- **代码**：可运行，含必要依赖文件（requirements.txt）
- **架构图**：包含组件、数据流向、协议标注（手绘/Excalidraw/PlantUML 均可）
- **笔记**：Markdown 格式，记录关键发现和思考

## 检视问题
1. 本周学到的核心概念能否用一句话讲清楚？
2. 如果面试官让你现场画本周的系统设计图，能不能画出来？
3. 有没有留下可复用的代码或笔记？还是一遍过就忘了？
